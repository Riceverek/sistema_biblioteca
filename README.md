# 📚 Sistema de Gestión de Biblioteca

## 🎯 Objetivo

Desarrollar un sistema de gestión de biblioteca que permita digitalizar y optimizar la administración de recursos bibliográficos, usuarios y procesos de préstamo y devolución, garantizando un manejo organizado, eficiente y centralizado de la información.

## 📝 Descripción

Este proyecto consiste en el desarrollo de un software para la gestión integral de una biblioteca. Su propósito es facilitar el control del inventario bibliográfico, la administración de usuarios y el seguimiento de los préstamos y devoluciones de libros.

El sistema busca reducir los procesos manuales, mejorar la organización de la información y proporcionar una herramienta que facilite las tareas administrativas de una biblioteca.

## ⚙️ Funcionalidades principales

- **Gestión de libros:** registrar, consultar, actualizar y eliminar libros.
- **Gestión de usuarios:** administrar la información de los usuarios de la biblioteca.
- **Préstamos:** registrar y controlar los préstamos de libros.
- **Devoluciones:** gestionar la devolución de libros y actualizar su disponibilidad.
- **Inventario:** consultar el estado y la disponibilidad de los recursos bibliográficos.
- **Reportes:** consultar información relacionada con los libros, usuarios y préstamos.
